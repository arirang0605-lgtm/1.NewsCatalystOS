# V1.1 전력기기 선택형 분석 — 개발 시작

2026-10-18. 대화에서 제안한 두 번째 산업(변압기·차단기·배전설비)의 후속 개발을
명시적으로 선택하는 분석 옵션으로 시작한다. 기존 V1.0의 반도체 한 산업 범위와
완료 조건을 바꾸지 않으며, 새 산업의 운영 활성화 완료를 뜻하지 않는다.

## 현재 우선순위 바로잡기 — 2026-10-18 16:35 KST

사용자가 “아직도 반도체야? 전력기기 하기로 햇지않나?”라고 개발 대상을 재확인했다.
**현재 후속 개발은 전력기기(변압기·차단기·배전설비)이다.** 이 최신 사용자 지시는
과거 AGENTS/DECISIONS의 ‘V1.0 반도체 한 산업’ 제한과 잘못 이어진 반도체 NEXT_TASK보다
현재 작업 선택에 우선한다. V1.0 기록·정상 코드는 보존하며 기존 반도체 작업을
전력기기 진행률로 계산하거나 미확보 반도체 양성자료를 새 선행조건으로 만들지 않는다.

전력기기 선택형 분석은 이미 구현됐다. 다음은 이 문서 마지막에 기록한 미완료 경로인
**사용권을 확보한 공식 전력기기 계약·증설·생산 뉴스의 실제 입력 → 기존 POWER_EQUIPMENT
분석 → 분리 저장 → 원문 근거 조회·표준 출력** 연결이다. 기존216개 제목의 양성0 기록은
그 당시 자료에 한정한다. 새 증거 없이 같은 빈 자료 재분석이나 반도체 보완을 반복하지 않는다.
이번 우선순위 수정은 문서 변경이며 새 기능·실자료 연동 완료 선언이 아니다.

## 이번 구현

기존 승인 RSS → 수집 영수증/중복·시점 확인 → 규칙 분석 → 보고서·ThemeStore →
회사 원문 근거 조회 → 표준 재료 전달을 재사용한다. 새 수집기/점수 모델/데이터베이스
프레임워크 대신, 전력기기 문장 해석과 선택 인수만 추가한다.

- 대상: 변압기, 차단기, 수배전반·배전설비. 발전·원전·배터리·냉각까지 확대하지 않음.
- 사건: 공급계약 체결, 설비투자 결정·집행, 생산능력 확대, 생산·양산 개시,
  납품 개시. 같은 문장에 직접 명시된 회사·설비·행동을 사용한다.
- 투자 결정/예정과 출처가 보도한 집행·납품을 구분한다. 출처 보도는 독립적으로
  확인한 거래·매출·수혜가 아니다. 전력망/데이터센터 투자라는 이유만으로 공급사를
  만들지 않으며, 이름만으로 DART 기업코드나 종목코드를 추정하지 않는다.
- Transformer AI와 전력반도체는 변압기로 분류하지 않는다. 복수 기업/복수 제품,
  모호한 행동은 임의로 짝짓지 않는다. 취소·철회·루머는 신규 계약으로 인식하지 않는다.
  최초 버전에서 복잡한 계약 정정·철회 이력 연결을 자동 완성했다고 주장하지 않는다.

## 선택형 실행

기존 `scripts/run_feed_analysis.py`에 `--industry POWER_EQUIPMENT`를 지정한다.
기존 승인 `--registry`, `--inbox-root`, `--state`는 읽기 전용으로 재사용하고,
별도의 `--analysis-root`와 `--theme-root`를 모두 명시해야 한다. 기존 반도체 파생
데이터에 전력기기 분석을 덮어쓰거나 그 반대의 혼용을 금지한다.

기존 `scripts/search_themes.py --materials --material-industry POWER_EQUIPMENT`
및 `--export-root`로 조건부 기업영향/반증과 신규·반복 판단을 동일 표준 JSON에
포함할 수 있다. 산업 기본값은 SEMICONDUCTOR이고 기존 예약·운영 API는 그대로다.
초기 선택형 프로필은 규칙 분석만 수행하며 새 AI 비용·모델 설정 권한을 사용하지 않는다.
새 라이브러리는 필요하지 않아 기존 프로젝트 모듈과 Python 표준 라이브러리를 재사용했다.

## 완료와 미완료

합성 제목 7개를 기존 수집 영수증부터 분석·테마·원문 조회·재료 전달까지 처리했다.
관련 시험 157 PASS/FAIL0. 이들은 합성자료이며 실제 회사 사건으로 세지 않는다.

기존 승인 저장 기사 216개(6개 제공자)를 별도 개발 폴더에서 실제 재분석했으나,
현재 저장분에 해당 전력기기 제목/경제사건은 0건이었다. 원본·운영 설정 등 18개
파일은 재분석 전후 SHA가 같았다. 새 RSS 요청·유료 AI 호출은 0회다.

따라서 **선택형 코드/합성 정상 경로는 구현됐지만 새 산업의 실자료 사건 검증과
정기 모니터링은 아직 완료하지 않았다.** 다음 핵심은 사용권이 확보된 공식
전력기기 계약·증설·양산 뉴스의 실제 입력을 기존 경로에 연결하는 것이다.
EraLeader의 반도체 재료 선정 연결은 별도 프로젝트의 완료 기록을 존중하며,
미완료로 되돌리거나 상대 코드/DB/Git을 수정하지 않는다.
