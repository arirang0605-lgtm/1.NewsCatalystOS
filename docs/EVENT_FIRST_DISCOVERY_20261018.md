# 사용자 승인: 경제 변화 먼저, 산업·기업 연결은 다음 — 2026-10-18

사용자 요청 “개발 진행하자”에 따라 산업별 분석기를 먼저 추가하는 순서보다
**허용된 뉴스 → 명시된 경제 행동 → 원문 대상·당사자 → 선택적 산업 분류 →
미분류를 포함한 관찰 후보**를 우선한다. 기존 반도체 V1과 전력기기 선택형 분석은
깊은 해석에 사용하는 기능으로 보존한다. V1을 다시 미완료로 만들지 않는다.

## 실제 입력 경로

기존 `run_feed_analysis.py --discover-economy`는 산업을 선택하지 않는다.
기존 승인 RSS의 완료 ACK, 원문 SHA와 시점 확인을 재사용하며, 먼저 공통 경제
행동을 추출하고 그 뒤 산업 단어를 연결한다. **산업 사전을 전부 비워도 같은
행동·회사·대상이 관측되는 시험**으로 입구의 산업 종속성을 제거했음을 확인한다.

명시된 계약·시설투자·생산·공급·서비스 개시·정책 지원을 한국어/영문 일부의
공통 문장 구조에서 처리한다. 처음 보는 제품명은 원문 관찰주제로 남긴다.
산업을 모르면 산업 미분류, 당사자를 모르면 회사 미확보로 남기며 사건 자체를
삭제하지 않는다. 회사명에 Quantum이 들어가거나 프로그램명이 CHIPS라는
이유만으로 업종을 추정하지 않는다. 문장 수식어·일반 소비자 표현도 기업명으로
만들지 않는다. 지원 의향·계획과 보도된 개시는 구별한다.

## 기존 기능과 연결

원래 수집기, 분석 보고서, ThemeStore, 사건 비교·조건부 영향과 반증,
표준 theme_delivery를 재사용한다. 신규의 것은 발견 문장 해석과 분류 보완,
기존 보고서를 보여주는 관찰 조회다. 새 거래·기업 평가·순위·매매 모델은 없다.
`--material-industry ALL_DISCOVERED`는 산업 태그 없는 후보까지 전달할 수 있다.

기존 시간당 research-approved의 선택 인수:
`--economic-discovery-root <News 전용 파생 폴더>` 및
`--discovery-source-base <현재 core/MOTIR 데이터 기준 폴더>`.
수집을 다시 하지 않고 해당 실행에서 이미 확보된 승인 저장 제목을 읽는다.
프로필 저장영역과 반도체 파생 DB는 분리하며, 산업발견 실패가 기존 운영 뉴스를
막지 않도록 결과를 분리한다. 출처권리·원문/발행시각·비밀·PIT·예산은 유지한다.

운영 시 `/api/economic-discovery`와 기존 대시보드의 “뉴스에서 발견한 경제 변화·
관찰 분야”에서 결과를 읽는다. `export=1`은 기존 표준 JSON의 별도 선택 출력이다.
미분류 발견을 기존 반도체 확정 공급망·Era 주도주 점수에 자동 가산하지 않는다.

## 사실과 범위

관찰 분야 힌트는 원문의 제품·대상 표현에서 붙인 분류이지 산업 심층검증 완료가
아니다. 미래수혜·주가·독립 공시 진위·시장 신규성은 확정하지 않는다. 로컬 처음
분석한 이전 뉴스가 오늘 발생한 사건으로 바뀌지 않는다. 발행시각을 모르면 null.

등록된 출처의 현재 저장 제목을 보고서당100개씩 나누어 처리한다. 처음에는
최근100개 밖의 오래된 제목이 계속 남는 문제가 있었으나, 같은 관측시각으로
후속 페이지를 이어 처리해 당시 제공자 저장분을 끝까지 관찰하도록 보완했다.
페이지 실패·원자료 판본 수 변경은 해당 출처에 has_more_older_titles로 남기고
다른 정상 출처는 계속한다. 조회·반복 분석은 새 기사 수집이 아니다.
인터넷 전체 기사, 모든 언어·복잡한 문장, 새 공급원의 이용허가까지 해결한 것은
아니다. 새 산업을 발견해도 수집권한이나 심층 공급망 검증을 자동 승인하지 않는다.
초기 공통 관찰은 유료 AI 없이 실행된다. 중요한 신규·변경 사건만 기존 예산 내
AI를 사용하는 원칙은 유지하며 필요시 그 별도 경로를 보완한다.

새 라이브러리는 필요하지 않다. 프로젝트의 경제행동 어휘·분류 보조·PIT·중복·
증거·조회 코드를 우선 사용하고 최소 연결만 추가했다. EraLeader의 이미 완료된
재료 선정 연결·코드·DB·Git·예약은 이번 작업에서 바꾸지 않는다.
