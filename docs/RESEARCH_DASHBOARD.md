# 로컬 조사 대시보드

이 Mac에서만 열리는 저장 RSS 분석 기록 화면이다. 일간 기록을 주간에서 집계·되짚고, 주간 결과를 월간에서 비교한다. 사용자가 남긴 일간 메모는 주간에, 주간 메모는 월간에 표시한다.

## 열기

```bash
python3 scripts/open_research_dashboard.py
```

브라우저에서 `http://127.0.0.1:8766/`을 연다. 서버를 끝내려면 실행 중인 터미널에서 Ctrl+C를 누른다. 다른 포트를 쓰려면 `--port`를 지정한다. 화면은 127.0.0.1에만 바인딩한다.

## 자료와 의미

- 입력: `output/feed_analysis/core/reports` 및 `motir/reports`의 기존 비공개 보고서. 신규 수집, AI 호출, 외부 프로젝트 쓰기, 거래 실행은 없다.
- 일간: 저장 보고서의 생산자 확인 시각과 행의 분석 가용시각 중 늦은 시각을 한국 시간 날짜로 묶는다. 같은 출처 버전을 재분석한 보고서는 가장 이른 확인 날짜에 한 번만 센다.
- 주간: 월요일~일요일의 일별 기록과 직접 메모를 집계한다. 월간: 달력 월의 주별 기록과 주간 메모를 되짚는다. 자동 피드백은 기록 수·보류 수·미확인 수의 변화만 말한다.
- 파일 이름의 SHA와 실제 바이트, 기존 저장 형식을 확인한다. 이 검사는 **로컬 파일 무결성**이며 생산자 독립 PIN, 원문 진위, 사실 검증 또는 실현 성과의 증명은 아니다. 읽지 못한 파일 수를 화면에 표시한다.
- 직접 메모: `~/Library/Application Support/NewsCatalystOS/dashboard/notes.jsonl`에 폴더 0700, 파일 0600으로 별도 저장한다. Git 대상이 아니며 분석 원본을 수정하지 않는다. 메모는 사용자의 의견이지 검증된 정답 라벨이 아니다.
- 브라우저 화면에는 저장된 제목·상태·출처 링크만 표시한다. 원문 본문, Gemini API 키, 운영 DB는 읽지 않는다.

이 대시보드는 원래 36개 구현 항목의 진행률이나 23/36 과거 인수 기록을 올리지 않는다.
