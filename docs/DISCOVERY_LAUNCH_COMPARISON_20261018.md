# 같은 회사·제품의 출시 제목 비교 — 기존 관측 보존

## 실제 입력과 출력

기존 사건 우선 발견에서 저장한 PRODUCT_LAUNCH 관측을 읽고, **같은 제목에 직접
명시된 회사명과 제품명이 정확히 일치하는 관측**을 나란히 비교한다. 기존
보고서/PIT·SHA 확인, 원문 제품 span, normalized 함수, ThemeStore와 표준
선택 내보내기를 재사용한다. 새 번역·별칭사전·종목검색·수집/AI·순위모델은 없다.

결과는 기존 `/api/economic-discovery`의 launch_comparisons와 화면 상단의
“같은 회사·제품의 출시 보도 비교”에 표시한다. ?export=1은 관련 원테마에
선택적인 discovery_launch_comparison을 추가한다. 다른 산업과 미분류도 동작한다.

## 판정의 구분

- IDENTICAL_TITLE_CONTENT: 정규화된 표시 제목 bytes가 동일한 원자료. 추가 출처
  자체를 새 제목 정보로 가산할 근거 없음. 원 raw title SHA는 별도로 유지.
- SAME_SOURCE_TITLE_REVISION: 같은 제공자 문서 식별자의 제목 판본이 달라짐.
  단순 수정·실질 변경은 아직 구분되지 않으므로 원문/단계 차이를 함께 표시.
- REPORTED_PHASE_DIFFERENCE: 같은 회사·제품의 계획/출시 보도 단계가 다름.
  같은 계획의 실제 이행으로 확정하지 않고 상대 제목을 재평가 근거로 보여줌.
- SAME_COMPANY_PRODUCT_ONLY: 회사·제품·출시행동만 일치. 한영 표기 차이는 보여도
  번역/재배포 또는 별도 발표인지 미확인. 같은 제품을 서로 다른 날 발표할 수 있음.

모든 원문·사건·테마·집계·독립성 미확인 상태를 유지한다. 비교 대상이 생겼다고
두 사건을 하나로 병합하거나 기업점수/시장 신규성 값을 바꾸지 않는다. 제품 버전
숫자·문장부호를 지우지 않으며 회사 별칭/번역명·제품 부분일치로 추정하지 않는다.
회사 미확보, 모호한 복수 당사자, 잘린 제품명은 이 정확이름 비교에서 빠질 수
있지만 경제 관찰 자체는 계속 남는다. 비교가 없다고 독립성을 인증하지 않는다.

## 이력과 재실행

기존 승인 분석보고서에 연결된 원문 span·raw title SHA·report SHA와 두 판본의
가용시각을 함께 내보낸다. 비교는 해당 시점에 저장된 근거로 재구성한 결과다.
둘 다 확보되지 않은 과거조회에는 비교가 없고, 나중 근거를 붙인 선택 export는
가용시각을 명시한다. 비교 ID는 조회시간이 아니라 원문 판본/사건 ID로 만든다.
재분석으로 원관측이 반복돼도 비교쌍/주제를 중복 생성하지 않는다. 기존 보고서,
ThemeStore, source DB·예약·비용·Era 상태에 쓰기 작업을 하지 않는다.

## 실자료와 시험

현재 자료의 UVJC/NovaJet 한영 제목2개가 같은 회사·제품 비교쌍으로 연결된다.
서로 다른 출처 문서이며 같은 실제 발표라고 확정하지 않는다. 기존45주제·50
출처관측을 그대로 두고 비교묶음1을 추가한다. 기존19개 보호파일과35개 분석보고서
SHA불변 확인. 관련175PASS/FAIL0, HTTP·선택export와 UI 문구도 검증.
동일제목·같은문서수정·단계차이의 양성경로 및 다른회사/제품버전·미확보·과거시점
음성경로 포함. 새로운 인적검수·개발완료조건을 추가하지 않는다.
