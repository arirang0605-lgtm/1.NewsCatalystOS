# V1.0 뉴스 기사 검증 기준 변경 — 2026-10-15 사용자 결정

사용자는 모든 뉴스 기사에 대한 별도 사람 검수와 두 검수자·500건 독립 라벨을 V1.0 출시 필수 조건에서 제외했다. 외부 검수 인력 의뢰도 진행하지 않는다. 기존 Gold 도구와 데이터는 선택적 품질 연구용으로 보존하며, 없는 정답을 AI가 작성하거나 정확도 수치로 발표하지 않는다.

## 입력과 출력의 의미

- 승인된 출처의 수집 영수증·원본 URL·관측시각·SHA가 있으면 기사 제목/허가된 본문을 **출처가 보도한 주장**으로 분석한다. 별도 사람 검수는 필요하지 않다.
- RSS 제목만 수집한 출처는 본문을 읽었다고 표시하지 않는다. 원문 보관은 출처별 허가 범위에 따른다.
- 기사 게재 확인은 계약 체결·납품·매출·투자수익의 독립 확인이 아니다. 출력에서 사실/보도/추론을 구분하고, 근거 없는 확정·매매 주문을 하지 않는다.
- 숫자와 확정 표현은 해당 문장의 출처를 연결한다. 자료가 없거나 모순되면 미확인으로 남긴다.

## 출시 점검 적용

`release_readiness.py`에서 사람 정답 500건, 그 정답에 의존하는 중복 정밀도·중요 사건 재현율·사실 추출 정확도·수혜 관계 정밀도와 누락 사례 인적 판정을 출시 차단 조건에서 제외했다. 해당 수치는 미측정이며 목표 달성을 주장하지 않는다. 실제 AI 호출·비용, 출처 연결, 5개 실제 거래일 운영, 물리 장치 복원, EraLeader 읽기 전용 소비, 전체 회귀 시험, P0/P1 장애 없음과 최종 출시 결정은 별도 확인한다.

기존 사람 작성 관계 검토 경로는 선택적 고신뢰 자료 입력으로 남겨둔다. 뉴스 기사의 자동 분석은 그 경로를 통과했다고 가장하지 않는다.

산업부 정기 수집의 평가용 Gold 후보 동결은 기본 실행에서 제외하고, 연구할 때만 `--capture-gold`로 실행한다. 선택적 연구 저장소의 장애를 뉴스 수집·분석 장애나 출시 차단으로 해석하지 않는다.

## 새 실자료 경로

산업통상부 보도자료 게시판은 공공누리 제1유형(출처표시)을 게시한다: https://www.motir.go.kr/kor/article/ATCL3f49a5a8c. 공공누리 제1유형은 출처표시와 상업·비상업적 이용 및 변형을 허용한다고 안내한다: https://www.kogl.or.kr/info/freeUse.do. 적용은 해당 부처 보도자료의 텍스트로 좁혔고, 첨부물·사진·제3자 자료는 제외했다.

2025-11-12 산업통상부 ASML 화성캠퍼스 보도자료 https://www.motir.go.kr/kor/article/ATCL3f49a5a8c/171178/view 의 본문 텍스트 2,535바이트를 실제 비공개 아카이브에 보관했다. 명시적인 공급관계 문장에서 ASML→삼성전자·SK하이닉스 **출처 보도 후보 2건**을 비공개 게시했다. 별도 읽기 전용 프로세스에서 삼성전자 후보의 SHA/PIT/미확정 상태를 확인했다. 이는 **2025년 보도된 관계에 대한 자료**이지 2026-10-15 새 사건이나 실제 계약 이행 인증이 아니다. 회사 공식 ID와 실제 수혜·매출은 미확인이다. URL/출처/HTML SHA/문서 SHA/영수증은 비공개 보관 경로로 확인 가능하다. 공개 Git에는 본문을 넣지 않는다.

현재 출시 인수의 과거 기록 23/36과 기능 구현 36/36은 재계산하지 않는다. 새 기준으로 실제 인수 증거를 다시 점검해야 하며, 현재 신규 사건 관계 출력·실 AI 생성·5거래일 운영·최종 릴리스는 아직 완료되지 않았다.
